# Madhuram Cafe

Simple Node.js app scaffold with a frontend-style source structure.

## Project structure

src/
 ├── assets/
 ├── components/
 │    ├── Navbar/
 │    ├── Hero/
 │    ├── CategoryCard/
 │    ├── ProductCard/
 │    ├── OfferBanner/
 │    ├── CartDrawer/
 │    ├── ReviewCard/
 │    └── Footer/
 ├── pages/
 │    ├── Home/
 │    ├── Menu/
 │    ├── Product/
 │    ├── Cart/
 │    ├── Checkout/
 │    ├── Orders/
 │    ├── Profile/
 │    ├── Login/
 │    └── Register/
 ├── services/
 ├── hooks/
 ├── utils/
 └── routes/

## Usage

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Open http://localhost:3000
